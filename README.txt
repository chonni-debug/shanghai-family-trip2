Shanghai Family Trip PWA v1.15 — Reliable Images & Maps

วิธีเปิดบนคอมพิวเตอร์
1. คลิกขวา ZIP แล้วเลือก Extract All / แตกไฟล์ทั้งหมด
2. เปิดโฟลเดอร์ที่แตกแล้ว
3. ตรวจว่ามี index.html และโฟลเดอร์ images อยู่ข้างกัน
4. เปิด index.html

วิธีนำขึ้นเว็บไซต์หรือแชร์ให้มือถือ
1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยคงโครงสร้างเดิม
2. ต้องมี images/ อยู่ระดับเดียวกับ index.html
3. เปิดผ่าน HTTPS เพื่อให้ PWA, Offline cache และแผนที่ทำงานครบ

ห้ามเปิด index.html จากภายใน ZIP และห้ามส่งเฉพาะ index.html

แผนที่
- แผนที่จริงต้องใช้อินเทอร์เน็ต
- มีพื้นหลังแผนที่สำรองเมื่อเซิร์ฟเวอร์แผนที่โหลดช้า
- หากแผนที่ออนไลน์ไม่ครบ ให้ใช้ปุ่ม AMap หรือ Google Maps ใต้แผนที่
